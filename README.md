# Фармакология — тренажёр (PWA)

## Файлы
- `index.html` — разметка и подключение остальных файлов.
- `style.css` — все стили.
- `data.js` — база препаратов: `DB` (список) и `INFO` (сведения для карточек). Подключается раньше `app.js`.
- `recipe-bot.js` — Recipe-бот: приводит текст рецепта к шаблону («Загрузить рецепты» в «Моих рецептах»).
- `app.js` — вся логика приложения (тесты, «Впиши сам», «Мои рецепты», группы, подсказки). В «Моих рецептах»: серия добавления («Сохранить и добавить ещё» — рецепты пишутся сразу, перезагрузка страницы откладывается до выхода из редактора, см. `myrxSeries`), создание рецепта прямо из папки, выбор нескольких рецептов (кнопка «Выбрать» или долгое нажатие; удаление и «В папку», см. `myrxSel`). Подсказки описаны в объекте `TOURS`: у каждого экрана свой ключ в localStorage, показываются один раз; ссылка «Показать обучение» на главном экране сбрасывает все.
- `manifest.webmanifest` — описание приложения для установки на телефон.
- `diag.js` — ВРЕМЕННАЯ диагностика зависания экрана (кнопка «🐞 Диагностика» справа вверху). После поиска бага удалить, как описано в комментарии в начале файла.
- `sw.js` — работа без интернета (service worker).
- `icons/` — SVG-иконки интерфейса и PNG-иконки приложения.
- `.nojekyll` — нужен для GitHub Pages.
- `build.sh` — сборка для публикации: сжимает JS и CSS в папку `dist/` (см. «Сборка»).
- `dist/` — готовая сжатая версия; создаётся `build.sh`, руками не правится.

Порядок подключения в `index.html` менять нельзя: `data.js` → `recipe-bot.js` → `app.js`.

## Сборка (сжатие JS и CSS)
Правьте исходные файлы в корне проекта, затем запустите `./build.sh` (нужен Node.js, остальное скачается само). В папке `dist/` появятся те же файлы, но `app.js`, `data.js`, `recipe-bot.js`, `style.css`, `theme-dark.css` сжаты: передача по сети (с gzip) примерно на четверть меньше, а размер JS и CSS для разбора браузером — около 375 КБ вместо 485 КБ. Поведение и внешний вид не меняются. Номер версии в `sw.js` увеличивайте до сборки.

## Публикация на GitHub Pages
1. Загрузите в корень репозитория всё СОДЕРЖИМОЕ папки `dist/` (включая папку `icons` и файл `.nojekyll`). Без сборки можно загрузить и исходные файлы из корня проекта: приложение будет работать так же, только тяжелее.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Откройте `https://<имя>.github.io/<репозиторий>/` на телефоне ОДИН РАЗ с интернетом: файлы сохранятся в кэш.

## Установка на телефон
- Android (Chrome): меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- iPhone (Safari): «Поделиться» → «На экран „Домой“».

## Обновление
Изменили любой файл (`index.html`, `style.css`, `data.js`, `app.js`, иконки) — увеличьте номер в `sw.js`
(сейчас `pharma-v103`), иначе телефон будет показывать старую версию из кэша.
Новая версия появится при втором открытии приложения.
Если добавляете новый файл в проект, впишите его и в список `CORE` в `sw.js`.

## Избранное
Звёздочка ☆ в углу карточки добавляет препарат в избранное (хранится на устройстве, ключ `pharma_fav_v1`). Когда в избранном что-то есть, на главном экране появляется пункт «Избранное» — карточки только отмеченных препаратов.

## Счётчик посещений (GoatCounter)
Подключён в конце `index.html` (блок «Счётчик посещений»). Без cookie и личных данных, баннер согласия не нужен.
1. Зарегистрируйтесь на https://www.goatcounter.com/signup (бесплатно для некоммерческого использования), придумайте код сайта, например `pharma-trainer`.
2. В `index.html` замените `var CODE="КОД"` на свой код, увеличьте номер в `sw.js`, соберите (`./build.sh`) и опубликуйте.
3. Статистика: `https://<код>.goatcounter.com` (вход по e-mail и паролю).

Что видно: посетители по дням; страница `/` — открыли в браузере, `/app` — запустили установленное приложение; событие `install` — установили на телефон (только Android/Chrome); страны, устройства, языки; откуда пришли.
Чтобы понять, какой канал сработал, раздавайте ссылки с меткой: `https://<имя>.github.io/<репозиторий>/?ref=группа-1`, `?ref=telegram`, `?ref=курс-2` — метка появится в «Referrers».
Свои заходы: один раз откройте сайт как `.../?nocount=1` на каждом своём устройстве.
Офлайн-запуски не считаются (сайт не может отправить запрос), поэтому цифры немного занижены.

## Локальная проверка
`python3 -m http.server` в этой папке, затем http://localhost:8000 (по `file://` иконки и офлайн-режим не работают).

## Заставка при запуске

Продолжает системную заставку Android (иконка на фоне `background_color` из манифеста): накладка `#splash` в `index.html` рисует тот же кадр, затем иконка уменьшается, а фон плавно приходит к цвету выбранной темы. Показывается только в установленном приложении; в браузере проверить можно адресом `?splash=1`. Размер и скорость — переменные `--splash-box` (белый квадрат, 240), `--splash-size` (картинка внутри него, 208), `--splash-hold`, `--splash-dur` в начале `index.html`; если размер не совпал с системной заставкой, подберите `--splash-box` и `--splash-size`.

## Локальный профиль

Вкладка «Профиль» открывает необязательную регистрацию по почте. В этой версии сервис в `profile-auth.js` имитирует отправку кода и показывает его прямо в форме. Код действует 10 минут в текущей вкладке. Профили, уменьшенные аватары и текущий вход сохраняются в браузере. Для проверки пароля хранится результат PBKDF2-SHA-256 с индивидуальной солью. Учебный прогресс по-прежнему относится к устройству и доступен гостю.

При подключении сервера замените локальные операции регистрации, входа, подтверждения и восстановления в `profile-auth.js` на вызовы API. Выдачу и проверку одноразовых кодов, отправку писем, проверку пароля и управление сессиями должен выполнять сервер. В форме подтверждения в `profile.js` замените демонстрационный код уведомлением об отправке письма.
