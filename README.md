# Фармакология — тренажёр (PWA)

Файлы: `index.html` (страница), `data.js` (препараты), `icons/` (SVG-иконки интерфейса и PNG-иконки приложения),
`manifest.webmanifest` (описание приложения), `sw.js` (работа без интернета).

## Публикация на GitHub Pages
1. Загрузите все файлы (включая папку `icons` и файл `.nojekyll`) в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Откройте `https://<имя>.github.io/<репозиторий>/` на телефоне ОДИН РАЗ с интернетом: файлы сохранятся в кэш.

## Установка на телефон
- Android (Chrome): меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- iPhone (Safari): «Поделиться» → «На экран „Домой“».
После установки приложение открывается без адресной строки и работает без интернета.

## Обновление
Изменили `data.js`, `index.html` или иконки — увеличьте номер в `sw.js` (`pharma-v1` → `pharma-v2`),
иначе телефон будет показывать старую версию из кэша. Новая версия появится при втором открытии приложения.

## Локальная проверка
`python3 -m http.server` в этой папке, затем http://localhost:8000 (по `file://` иконки и офлайн-режим не работают).
